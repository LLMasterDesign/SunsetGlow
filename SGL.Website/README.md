# Sunset Glow Lighting - Website

**Live:** https://sunsetglowlighting.com  
**Status:** ✅ Production (Netlify)

Veteran-owned holiday lighting company in Princeton, TX. Professional static site with Netlify Forms integration.

## Quick Links
- **Live site:** sunsetglowlighting.com

## Features
✅ Modal estimate form with photo upload  
✅ Clickable package tiers (4 levels with pricing modals)  
✅ Netlify Forms (multipart file support)  
✅ SEO optimized (sitemap, schema, OG/Twitter cards)  
✅ Mobile-first responsive design  
✅ Accessibility (ARIA, keyboard nav, screen reader friendly)  

## File Reference
- `index.html` — Homepage (hero, packages, testimonials, modals)
- `services.html` — 4-tier package details
- `about.html` — Company story, veteran values
- `contact.html` — Full contact form + FAQ
- `blog.html` — Resources, tips, local events
- `service-book.html` — Service overview
- `thanks.html` — Post-submission thank-you
- `404.html` — Custom error page
- `styles.css` — All styling (1400+ lines, mobile-first)
- `script.js` — Forms, validation, modals, navigation
- `CHANGELOG.md` — Detailed change history

## Deploy Updates
1. Make edits to files
2. Push to GitHub (see Master README for Git setup)
3. Netlify auto-deploys in ~1-2 minutes

Or drag updated folder to Netlify dashboard.
