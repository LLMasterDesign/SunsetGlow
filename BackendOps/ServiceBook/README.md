# Service Book (Internal Working Copy)

This folder holds the internal source/spec for the public Service Book. The live public page is `SGL.Website/service-book.html`. Build and iterate here; when ready, copy distilled content to the website.

Contents
- `SPEC.prompt.txt` — canonical spec/prompt (source of truth)
- `index.html` — optional single-file draft (self-contained) for review

Workflow
1. Edit `SPEC.prompt.txt` (brand vars, catalog, pricing, copy).
2. Generate or update a draft `index.html` here if needed.
3. When approved, update `SGL.Website/service-book.html` for production.
